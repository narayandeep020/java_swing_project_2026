# 🚌 Bus Booking System

A Java-based Bus Booking System that allows users to search, book, and manage bus tickets efficiently.  
This project demonstrates core concepts of **Java programming, JDBC, MySQL integration, and Swing & AWT**.

---

## 📖 Features
- Select Username
- Search buses by source, destination, and date
- Book tickets with seat 
- Number of passenger selection
- View booking history
- Database-driven with **MySQL + JDBC**
- Error handling and validation for robust performance

---

## 🛠️ Tech Stack
- **Language:** Java (JDK 8+)
- **Database:** MySQL
- **Frameworks/Libraries:** JDBC, Java Collections, Swing ,Logger
- **Tools:** Eclipse/IntelliJ IDEA,
